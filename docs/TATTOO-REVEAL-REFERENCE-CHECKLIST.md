# Klipr Tattoo Reveal — reference-picking checklist

Purpose: make sending the Phase 1 reference set fast. This is NOT the recipe.
The recipe is written later, from the traits these picks share (spec quality gate:
20–30 videos, AI breakdown reviewed by Matt, then recipe, then the pass test —
Matt would post the output without re-editing).

## How to send picks (any of these is enough to start)
- Paste links here, or drop the videos in the Drive folder Muse posts from.
- A smaller starter set (5–10) is enough to prove the pipeline while the full
  20–30 are collected — the assistant already offered this on 2026-10-25.
- Pick reels you would actually post, not just reels you like: the set defines
  what "good" means for the template.

## What to look for in each pick (the spec's breakdown traits)
1. Hook length — how fast does the finished piece flash? (first 1–2s is the bar)
2. Cut rhythm — how many shots, and how long does each shot hold?
3. Camera moves — punch-in, push-in, pan, static, or a mix? Which move sells it?
4. Caption size / position / timing — where does text sit, and for how long?
   CORRECTION 2026-10-25 16:33 EDT (supersedes any IG v2 note here): in Klipr,
   text overlay is user-controlled in the editor — position, size, font and
   timing are the user's / brand kit's choice, not a template rule. Record
   what each pick does as an observed trait only; do NOT encode IG v2 into
   the recipe. Matt's IG v2 rules are his personal posting preference for his
   own tattoo accounts and may be applied by him at posting time for a
   Shyftd.ink test, but they are not a Klipr rule. The spec's lower_third
   example is just an example, not a preset.
5. Music energy curve — does it build, stay flat, or hit on the reveal?
6. Payoff point — at what second does the finished piece land, and what comes
   after it (slow showcase, detail shots, still end card)?

## One-line note per pick (optional, helps a lot)
Example: "hook under 1s, 3 punch-ins, payoff at 4s, slow showcase after."
If a pick is a near-miss, say why — near-misses sharpen the recipe too.

## What NOT to send for this template
- Process / needle / machine footage as the model for tattoo b-roll: tattoo
  templates block generative tattoo detail. Tattoo b-roll is photo-motion from
  real photos + scene ambiance only. (Spec correction, locked 2026-10-25.)
- Reels whose only strength is a trending song — Klipr ships royalty-free
  music; trending sounds are added in the IG/TikTok app on export if wanted.
